## 1. The question

Is there one structure in which every live, verified axiom of the formal Abhidhamma holds at once, and in which every
kind of thing those axioms name actually occurs?

If there is, the structure is the model, and the book is about it. If there is not, the attempt finds each smallest set
of axioms that cannot hold together, and the book is about those.

A model shows only that the axioms do not contradict one another. It does not show that they are true, that they are
faithful to the texts, or that the world is like the model. It is one witness, not a picture of anything.

## 2. What "the whole" covers in this attempt

**Included:** every row of `kala/AXIOMS.md` that is VERIFIED and not HELD OUT. At the drafting commit, that is **127
rows**: 132 rows, minus four HELD OUT rows (A59, A69, A102, A119), which record the texts' own conclusions and belong to
the test bank in `kala/ANSWERS.md`, and minus one RECALLED row (A12), which has not yet been read at its line.

**Not included:** A0 and A0′, which are choices about windows onto the world, not axioms. This attempt faces inward and
takes no window.

**Not yet captured:** the axiom list follows the Abhidhammattha-saṅgaha's nine chapters, traced back to the Piṭaka
wherever the Piṭaka line was found. It does not yet hold the Yamaka, the Dhātukathā, the Puggalapaññatti, the
Paṭṭhāna's permutations across the matrix, or the Kathāvatthu beyond five debates. This attempt reaches what the list
holds and no further. Each later stage of capture is a new attempt, under its own protocol.

## 3. What the texts already say about the thesis

The texts assume consistency. They state it as a rule for reading, and they never prove it:

- **The Buddha's word does not contradict itself.** The Saṃyutta sub-commentary rejects a rival collection as not the
  Buddha's word "because it conflicts with the Buddha's word; for the Fully Awakened One does not say what contradicts
  itself earlier and later" (*na hi sambuddho pubbāparaviruddhaṃ vadati*, `s0302t.tik.xml:3083`).
- **The commentary teachers do not contradict themselves.** A Vinaya sub-commentary treats a clash inside the
  commentary as a copyist's slip, "for the commentary teachers do not say what contradicts itself earlier and later"
  (*na hi aṭṭhakathācariyā pubbāparaviruddhaṃ vadanti*, `vin06t.nrf.xml:1821`). It adds: wherever "others" or "some"
  are cited, examine well, keep what fits, and set the rest aside (`:1825`).
- **When teachers and texts clash, the reading that clashes with neither the Pāli nor the commentary wins.** The
  Dhammasaṅgaṇī's sub-commentary records a contradiction (*virodho siyā*) between "the teachers" and the commentary
  on concepts, and rules: "a meaning that contradicts neither the Pāli nor the commentary is to be taken, after
  examination" (*pāḷiyā aṭṭhakathāya ca aviruddho attho vicāretvā gahetabbo*, `abh01t.tik.xml:2545–2553`).

So the tradition claims consistency for the Buddha's word and for each teacher, and it keeps its own system consistent
by ranking its layers and setting aside the later voice. No text claims that the Piṭaka, the commentaries, the
sub-commentaries and the manual hold together as one system. The sub-commentaries record places where they do not.
This attempt tests what the tradition assumes, across all the layers at once. Section 5's layer order follows the
tradition's own ranking.

## 4. The formal statement

**One theory.** All axioms are written in one Lean 4 package, over one type, `World`, in the formal-abhidhamma
repository. (Today each run builds its own world, so this first requires the single importable package already
planned on the roadmap, A391.)

**Every live row is sorted into exactly one class** before any model is searched:

| Class | Meaning | Counted as tested? |
|---|---|---|
| **CONSTRAINT** | a definition `aNN_<name> : World → Prop`, named by the row's ID (the rubric's naming rule) | yes |
| **BY THE TYPE** | the row holds because of how `World` is built (for example, A7: time is a function on moments, never a moment). The field that carries it is named | no — listed separately |
| **NOT FORMALIZABLE** | the row cannot be stated without a choice the texts do not make (for example, A25 is a simile, "no other thing so quick to change"; A2b says past world-cycles are "not easy to count") | no — listed, with the reason |

**Richness.** An empty world satisfies every "for all" claim and proves nothing. So the model must also satisfy
**occurrence conditions**: every kind that a row names occurs somewhere in the model's history. Each condition cites its
row. The list includes at least: each of the 89 citta-types (A28), each of the 28 kinds of matter (A60), each of the 24
conditions holding between some pair (A78), each of the 31 planes with a stream in it at some time (A48), a full
five-door process with a very great object (A41), a mind-door process (A43), a death followed by a rebirth (A56–A58,
A122), a mindless existence and an immaterial existence (A13), a cessation attainment with its emergence (A111–A112), a
path process (A109), matter outside any being (A64, A66), a full moon (A20), and a stream that ends at an arahant's last
moment (C with A8). The full list is frozen with the encoding (section 8).

**The statement, layer by layer:**

```lean
-- the model: one world where every constraint and every occurrence condition of the layer holds
theorem model_Lk : ∃ w : World, occurs_citta_types w ∧ … ∧ a1_one_at_a_time w ∧ a3_proximity w ∧ …

-- a contradiction, if one is found: a set of constraints with no world at all
theorem clash_n : ¬ ∃ w : World, aX w ∧ aY w ∧ aZ w
-- …and it is smallest: drop any one member, and a world exists
theorem clash_n_minimal_X : ∃ w : World, aY w ∧ aZ w   -- and likewise for Y and for Z
```

Each premise is its own definition, never a bundle, so Lean can report which ones a result uses.

## 5. Layers

There is one model per layer. Each layer adds rows to the one before it, in the rubric's tier order:

1. **L1 — the Piṭaka**
2. **L2 — plus the commentaries** (the aṭṭhakathā, the Visuddhimagga)
3. **L3 — plus the sub-commentaries** (the ṭīkā)
4. **L4 — plus the manual** (the Abhidhammattha-saṅgaha)
5. **L5 — plus the manual's commentary** (the Vibhāvinī)

A row whose clauses come from different tiers is split, and each clause enters at its own tier. A118's split is the
precedent: its wording is Piṭaka, and its scope is sub-commentarial. The attempt builds L1 first. Each later layer
either extends the model or meets a contradiction. The result names the largest layer with a model.

## 6. Rival readings

Three rows record a dispute inside the tradition: A4 (17 mind-moments, against a ṭīkā's 16⅓ and 16), A9 (the
classification of space) and A129 (the kalāpa's size). Each enters at the reading the row states first. Each rival
reading is a **variant**, tested in its own model.

Two rival readings are never entered together. That would be a contradiction by entry, not a finding. Rivals already
held out (A119) stay out.

## 7. Encoding rules — against a model made easy

An author who wants a model is tempted to write each axiom a little weaker than its text. These rules work against that.

1. **Literal first.** Each row says what its own words say, with only the scope that its own row records (A47 carries
   the Vibhāvinī's exception for cessation because the row quotes it). A scope that only another text supplies is never
   added silently. If the literal reading meets a contradiction that a scope would remove, the result is reported as a
   **scope collision**, with the line that supplies the scope, if any text does.
2. **Teeth.** Every constraint comes with a **forbidden world**: a small world its text rules out, where Lean proves the
   definition false. A definition with no forbidden world is `True` in disguise, and it is refused.
3. **Blind back-translation** of every definition. A copy with the comments stripped goes to a reader that loads no
   doctrine, and that reader's plain-English reading is compared with the row. A mismatch is fixed in the definition,
   never explained away.
4. **The refuter checks the encoding in both directions:** too strong (it adds what the Pāli does not say, which
   manufactures a contradiction) and too weak (it says less, which manufactures a model). The second risk is the larger
   one here, and the refuter is told so.
5. **No answer is a premise.** HELD OUT rows and `ANSWERS.md` never enter. `scripts/leak-check.py` runs on every
   layer's full premise set.
6. **Freedoms are declared.** Everything `World` leaves open (for example, how light travels between the sun, Sineru
   and the moon, how many world-systems there are, where the history starts) is listed before the search. A model that
   needs a freedom some live row closes does not count.
7. **The undeclared questions stay undeclared.** The model holds streams and dhammas, never persons, so it says nothing
   about a Tathāgata after death. Wherever the build must choose something the texts leave open, the choice is
   declared. Where it is cheap, a second model makes the other choice, so that no single model can be read as settling
   the question.

## 8. The order of work

Every step is its own commit, stamped before the next one starts.

1. **This protocol:** approved, committed and stamped. It is the first file of this repository.
2. **The encoding** (formal-abhidhamma): the single package, every live row sorted and encoded with its forbidden world,
   blind back-translations, the refuter on the encoding, the occurrence list and the freedoms list. Then frozen.
3. **Protocol 2, the frozen statement:** the encoding's commit, every row's class, the occurrence list, the variants and
   the freedoms, registered through `runs/prereg.py --proof` and mirrored here, **before any model is searched**. Its
   approval is a table that gives, for every row, the axiom beside the blind reader's plain English. The founder reads
   that table.
4. **The attempt**, layer by layer: models and smallest contradictions in Lean, built in continuous integration, with
   breaks that must fail.
5. **The refuter on the result**, then the grade against the rubric, `RUN.md`, and `THEOREMS.md` regenerated.
6. **Only then, the chapters.**

## 9. Controls — the instrument must catch what it is for

- **The empty world must fail** the occurrence conditions. If it passes, the conditions are broken.
- **A planted contradiction must be found.** Enter A4's 17 and its rival 16 together, as one variant pair. The search
  must return that pair as a smallest contradiction. If it does not, the contradiction search is blind.
- **A planted weakening must be caught.** Replace one definition with `True`. Its forbidden-world check must fail.

## 10. What will be reported, whatever happens

- **For every one of the 127 rows,** its class: CONSTRAINT, BY THE TYPE, or NOT FORMALIZABLE (with the reason). The book
  states the three counts. It never says "all 127" if the counts say otherwise.
- **If a model exists,** for each layer: the model, the logic it needs (constructive or classical), and any constraint the
  model satisfies for a trivial reason.
- **If it does not,** every smallest contradiction found, with its layer and its kind: a **scope collision**, a **clash
  between teachers**, or a **contradiction inside one teacher's words**. The largest layer that still has a model is also
  reported. The book's subtitle then changes to say so. The new wording is the founder's to choose after the result;
  "One Model of the Whole Abhidhamma" does not stay on a book whose result is otherwise.
- **The test bank, as a second result.** The model is checked against every row of `kala/ANSWERS.md`. An answer that the
  model violates does not follow from the axioms. An answer that the model satisfies is consistent with them, and
  nothing more.
